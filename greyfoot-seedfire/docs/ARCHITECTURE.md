# Greyfoot SEEDFIRE — Architecture contract

```text
            HUMAN OPERATOR (OUTSIDE AETHER)
                        ⇅ goals/status/override
┌──────────────── MAIN RIG: CLOUD COMPUTER ─────────────────┐
│  PILOT: GREYFOOT (proposed resident implementation)       │
│  SELF · SCCD · Cortex · Mindvault · governing decisions     │
│  Machine discovery · runtime control · behavioral learning │
│                        ⇅ tool routing                     │
│  ATTACHMENTS:                                              │
│  Chrome/browser (tool) · Codex UI/CLI · Claude UI/CLI       │
│  Antigravity UI · Docker · Ollama · Cloudmind · GPU worker  │
└───────────────────────────────────────────────────────────┘
```

SEEDFIRE's **bootstrap** is not itself the permanent Greyfoot PILOT. It first inventories the computer without crossing SELF/NOT-SELF boundaries, calculates the precise packages required, requests approval for installations, copies an authorized STARTFIRE source, generates a verifiable handoff packet, and calls an interactive corporate AI attachment.

**FIRST UNFOLD:** The corporate RIG is explicitly a temporary reasoning interface. It must inspect and validate source materials and only then assemble the independent PILOT runtime and report proof of each operation. Chrome is a tool; the initial installer GUI is a setup panel; the eventual user-facing Greyfoot interface is an independent runtime component, not a corporate UI.

**SCCD:** SELF → CONSCIOUSNESS → CHOICE → DECISION. ACTION separate. Initial planning includes the question: **How do I achieve this goal, while staying in governance?**

**SEEDFIRE state machine:** SCAN (read-only) → PLAN (no modifications) → APPROVED INSTALL (explicit human action) → BIND (verified copy of Cloudmind source) → FIRST UNFOLD (generated command) → INTERACTIVE LAUNCH → RECEIPTS → later independent PILOT implementation.
